Уся Git-історія та код — **англійською**: коміт-меседжі, заголовки й описи пул-реквестів, і **всі коментарі в коді** (JSDoc, інлайн, Prisma-схема, CSS, .env.example). Решта (спілкування, документи в репо, UI застосунку, рядки локалізації) лишається українською. Сказано 17.07.2026 щодо [[madiro-project-goals]]: спершу про ПР-и, потім коміти, потім коментарі (наявні перекладено того ж дня).

**Why:** репозиторій публічний і йде в резюме — англомовну історію читає ширша аудиторія (рекрутери, потенційні колеги), на відміну від внутрішньої документації.

**How to apply:** `git commit -m`, `gh pr create --title/--body` і коментарі в коді — англійською. В англійських коментарях можна цитувати українські лейбли UI в лапках («Утеплення», «Ціна») — це посилання на продуктові рядки. Тестові описи (`it('...')`) поки українською — окремого рішення не було. Зміст документів у docs/ лишається українським; у описі ПР доречно зазначити, що документ українською. Виняток: перший коміт `docs: аналіз вимог Madiro...` (a99883e) лишено українською за рішенням користувача — не переписувати.
